# Ревью «Змейки»

Ревью — это сравнить «что сделано» с «как договаривались». Договорённости лежат
в трёх документах, проверяй по ним:

1. `docs/requirements.md` — каждое затронутое FR/NFR реализовано? Есть тест или
   запись в чек-листе приёмки? ID требования есть в коммит-месседжах?
2. `docs/architecture/modules.md` — изменение в правильном модуле (таблица
   «Куда класть новый код»)? Зависимости идут вниз по слоям? Контракт `tick`
   не размыт?
3. `docs/architecture/engineering.md` — тесты добавлены, коммиты в Conventional
   Commits, `main` зелёная?

## Частые нарушения — проверять в первую очередь

- DOM, canvas, localStorage, `Date.now()`, `Math.random()` внутри `src/core/`
- Мутация `GameState` вне функции `tick`
- «Магические числа» в логике вне `src/config.ts`
- Рендер, который что-то сохраняет, слушает или мутирует
- Фича без теста в `core`
- Новый side effect вне `input/`, `storage/`, `main.ts`
- `core/` импортирует что-то вне `core/`

## Формат вывода

Список: **нарушение → файл:строка → как чинить** — только реальные проблемы,
без придирок ради объёма. Если всё чисто — так и скажи одной строкой.
Каждое нарушение приведи к пункту документа-договорённости, который оно
нарушает, иначе это мнение, а не факт.
