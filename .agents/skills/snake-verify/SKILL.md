# Проверка «Змейки» (C + Raylib)

Шаги 1–2 — обязательный минимум после любого изменения кода. Дальше — по контексту.
Команды выполняются из окружения с `gcc/cmake/ninja` в PATH
(«MSYS2 MinGW64» или терминал с `C:\msys64\mingw64\bin` в PATH).

## 1. Сборка и тесты

```bash
cmake --preset default     # один раз после смены CMake-конфигурации
cmake --build build        # сборка; -Werror включён: ноль предупреждений (NFR-7)
ctest --test-dir build     # юнит-тесты Unity
```

Падение любого шага = проверка не пройдена, дальше не двигаться.
Ошибки компилятора цитируй целиком: файл, строку, текст.

## 2. Смоук-запуск игры

Нужно, когда правились `render/`, `input/`, экраны или `main.c`.
Запусти `./build/snake.exe` и прогони один раунд.

Чек-лист смоука:

- [ ] Из меню игра начинается, змейка движется вправо
- [ ] Повороты работают; разворот на 180° игнорируется (FR-4)
- [ ] Еда съедается, длина и счёт растут (FR-7)
- [ ] Столкновение со стеной и с собой → Game Over; «Заново» работает (FR-8, FR-9)
- [ ] Пауза останавливает движение и затемняет поле (FR-10)
- [ ] Рекорд сохраняется после перезапуска игры (FR-14)
- [ ] FPS не проседает, окно ведёт себя адекватно (NFR-1, NFR-5)

## 3. Отчёт

Отчитывайся честно и конкретно: какие шаги запущены, что зелёное, что сломано —
с текстом ошибки и командой, которая её дала. «Должно работать» — не результат;
результат — «проверил, работает» или «падает вот здесь».
